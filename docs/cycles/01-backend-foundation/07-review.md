# PR レビューの扱い

指摘そのものは PR のコメント。ここには、扱いのまとめだけを書く。

- PR ごとに1節にする
- 節の頭に、指摘の一覧の表（番号・印・何を・扱い）を置く
- 扱いに説明が要る指摘は、表の下に、指摘ごとの見出しを作って書く
