# プロダクトの目的

目的・利用者・範囲の正本。AGENTS.md の概要と Issue は、ここを参照する。ここを変えるときは、影響する要件（requirements/）も確かめる。

会員どうしがいいねを送り、お互いにいいねするとマッチして、メッセージを送り合えるマッチングアプリの API と画面。学習用で、まずレガシーコードの形で作り、測って直す過程を残す。

## 解決する問題

DB（テーブル設計・JOIN・インデックス・同時更新）・API・認証と認可の設計を、読んだ知識ではなく、作って測って直した事実として説明できるようにする。そのために、よくある機能を持つアプリを題材にする。

## 対象ユーザーと利用場面

| 利用者 | 場面 |
| --- | --- |
| 会員（無料・有料） | ブラウザから登録し、プロフィールの条件で相手を探し、いいね・メッセージを送る |
| 管理者（あとで作る） | 管理画面（`admin/`）で、会員とメッセージのやり取りを把握する |

## 主要な機能

個別の受け入れ条件は requirements/ に置く。

| 機能 | 中身 | いつ作るか |
| --- | --- | --- |
| 新規登録 | 性別・生年月日・メールアドレス・パスワードを入力し、メールアドレスを確認してから使える | 最初の範囲 |
| ログイン | メールアドレスとパスワードでログインする | 最初の範囲 |
| プロフィール | 自分のプロフィールを編集する。相手のプロフィールを見る。プロフィール画像はデモ用の画像を使う | 最初の範囲 |
| いいね | 相手にいいねを送る | 最初の範囲 |
| マッチ | お互いにいいねするとマッチになる。マッチした相手の一覧を見る | 最初の範囲 |
| 検索と一覧 | 相手のプロフィールの項目（性別・年齢の幅・都道府県・身長）で絞り込み、最終ログインが新しい順に並べる | 最初の範囲 |
| メッセージ | マッチした相手とメッセージを送り合う。相手ごとの最新の1件を一覧で見る | 最初の範囲 |
| ブロックと退会 | 相手をブロックする。退会する | 最初の範囲 |
| 有料会員 | 有料会員かどうかで、使える機能を分ける | 最初の範囲（有料かどうかだけ） |
| プランを増やす | 一般プランとプラチナプランに分け、プランごとに機能を制限する | あとで |
| 決済の通知 | 決済の結果の通知を受け取り、有料会員の状態を変える | あとで |
| 管理画面 | 管理者が会員とメッセージを見る。だれが何を見たかを残す | あとで（`admin/`。Laravel と React） |

## 成功基準

- 各機能で、要件のテストが、レガシー版と直した版の両方で通る（レガシー版にはテストを足してから直す）
- 直した機能ごとに、前と後の数字（クエリの数・時間・EXPLAIN の読んだ行の数）が、解説のページと [decisions.md](decisions.md) に残っている

## 業務上の不変条件

どの操作でも守る。レガシー版で守れていないものは、直す段階で守れるようにする（直す段階のテストの対象になる）。

1. 18歳未満は登録できない（生年月日から確かめる）
2. メールアドレスを確認していない会員は、ログインしても機能を使えない
3. 同じメールアドレスで2人は登録できない
4. 自分にはいいねできない
5. 同じ相手へのいいねは1回だけ
6. マッチした相手にだけメッセージを送れる
7. ブロックした・された相手は、検索にもメッセージにも出ない
8. 他人のいいね・マッチ・メッセージは見られない（管理者を除く）
9. 有料会員だけが使える機能は、無料の会員には使えない

## 対象外

- 本人確認の書類（年齢は生年月日の入力と確認だけ）。本当のサービスにするなら、出会い系サイト規制法（インターネット異性紹介事業を利用して児童を誘引する行為の規制等に関する法律）で、18歳以上かを公的な証明書などで確かめることが求められる。この学習では扱わない
- 本当の決済（決済会社には接続しない。通知は手で送る）
- 写真のアップロード（プロフィール画像は、シードで入れるデモ用の画像だけ）・通知（メール以外のプッシュなど）
- 実在の人の写真（デモ用の画像は、手元で作るイラストや頭文字の画像にする）
- 外へのメールの送信（確認のメールは、手元の Mailpit で受け取る）
- リリース（どこに出すかは、あとで決める）

## 用語

画面・コード・要件で同じ言葉を使う。

| 言葉 | 意味 | コードでの名前 |
| --- | --- | --- |
| 会員 | 登録した人 | `user` |
| プロフィール | 会員の公開する情報（性別・年齢・都道府県・身長・自己紹介・プロフィール画像） | `profile` |
| プロフィール画像 | プロフィールに出す画像。デモ用の画像のパスを持つ | `avatar_path` |
| メールアドレスの確認 | 登録したメールアドレスに届いたリンクを開いて、本人のものだと確かめること | `email_verification` |
| いいね | 会員が相手に好意を送ること。1人の相手に1回 | `like` |
| マッチ | お互いにいいねした状態 | `match`（PHP の予約語なので、クラス名は `UserMatch`） |
| メッセージ | マッチした相手に送る文 | `message` |
| ブロック | 相手を自分から見えなくし、相手からも見えなくすること | `block` |
| 退会 | 会員をやめること | `withdrawal` |
| 有料会員 | 料金を払っている会員 | `is_paid`（レガシー版。プランを増やすときに直す） |
| 管理者 | 管理画面を使う運営の人 | `admin` |
