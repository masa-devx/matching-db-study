# 画面のデザインの決まり

状態：確定（2026-11-13。03c で決めた）
決定：[decisions.md](decisions.md) の D-024
要件：[requirements/screens.md](requirements/screens.md) の FR-UI-023〜033・NFR-UI-004〜007
解説：[../explanations/03c-ui.html](../explanations/03c-ui.html)

画面（`frontend/`）の色・文字・余白・角丸・影・動きと、部品の見た目と動きの正本。レガシー版も改善版も、この値を使う。

- レガシー版：値を CSS に**そのまま書く**（`App.css`・`index.css`）。モーダル・トーストなどの部品も、画面ごとに書く（コピーになる）
- 改善版：値を `tokens.css` の CSS の変数（カスタムプロパティ）にまとめ、部品は1つずつ分ける

## トーン

「写真が主役で、やわらかく、押すと気持ちよく返ってくる」。

- 地は白ではなく、少し温かい色にする。カードは白で浮かせる
- 主な色はローズ。ボタンとマッチの演出だけ、ローズからコーラルへのグラデーションにする（使う場所を絞ると目立つ）
- 角は大きく丸める。影は薄く、広く
- 動きは短く。待たせる動き（長いアニメーション）は、マッチの演出だけにする

## 色

ライトだけ（ダークモードは対象外。[screens.md](requirements/screens.md) のスコープ外）。

| 名前（改善版の変数） | 値 | 使う場所 |
| --- | --- | --- |
| `--color-bg` | `#faf6f4` | 画面の地 |
| `--color-surface` | `#ffffff` | カード・モーダル・入力欄 |
| `--color-surface-2` | `#f4eeec` | スケルトン・相手の吹き出し・押せない入力欄 |
| `--color-text` | `#231c20` | 文字 |
| `--color-text-muted` | `#6f6368` | 補足・日時 |
| `--color-line` | `#ece3e1` | 枠線・区切り |
| `--color-primary` | `#d12f5f` | 主なボタンの文字・選んだタブ・リンク |
| `--color-primary-soft` | `#fdecf1` | 選んだ項目の地・「マッチ済み」の印 |
| `--gradient-primary` | `linear-gradient(135deg, #d63a5f 0%, #dc4e3c 100%)` | 主なボタン・自分の吹き出し・マッチの演出・未読のバッジ |
| `--color-success` | `#2f9e6a` | 成功のトースト |
| `--color-danger` | `#c23a3a` | 失敗のトースト・入力の誤り・ブロック・退会のボタン（06） |
| `--color-overlay` | `rgba(35, 28, 32, .45)` | モーダルの後ろ |

文字と地のコントラストは 4.5 以上にする（計算した値：`--color-text` と `--color-bg` で 15.5・`--color-text-muted` と `--color-bg` で 5.3・`--color-primary` と白で 4.9・白と `--color-danger` で 5.3）。グラデーションの上の白い文字は、濃い側で 4.5・薄い側で 4.0 なので、ボタンの文字は太字（600）にする。

## 文字

Web フォントは使わない（読み込みで LCP と CLS が変わり、04 の数字と比べにくくなるため）。

| 名前 | 値 |
| --- | --- |
| 書体 | `"Hiragino Sans", "Hiragino Kaku Gothic ProN", "Noto Sans JP", system-ui, sans-serif` |
| 数字・時刻 | `font-variant-numeric: tabular-nums`（桁がそろう） |
| 大きさ | 12（バッジ・日時）・14（補足）・16（本文・入力）・20（見出し）・24（画面の見出し）・32（マッチの演出） |
| 太さ | 400（本文）・600（名前・ボタン）・800（画面の見出し・ロゴ） |
| 行の高さ | 1.6（本文）・1.3（見出し） |
| 字間 | 見出しだけ `0.02em` |

## 動き

| 名前 | 時間 | 動き方（イージング） | 使う場所 |
| --- | --- | --- | --- |
| 速い | 150ms | `cubic-bezier(.2, .8, .2, 1)` | 押したとき（色・縮む）・フォーカスの枠 |
| 普通 | 250ms | `cubic-bezier(.2, .8, .2, 1)` | モーダル・トースト・画面の切り替え・吹き出しが出る |
| 弾む | 400ms | `cubic-bezier(.34, 1.56, .64, 1)` | いいねのハート・マッチの演出の写真 |
| 光る | 1.4s のくり返し | `ease-in-out` | スケルトン |

- 動かすのは `transform` と `opacity` だけ（`width`・`top`・`margin` を動かすと、まわりの並べ直しが起きて重くなり、CLS も悪くなる）
- 閉じるときは、開くときより少し速くする（200ms）
- OS で「視差効果を減らす」を選んだ人（`@media (prefers-reduced-motion: reduce)`）には、動きを止めて、出る・消えるだけにする

## 画面の切り替え

- React Router の `viewTransition`（ブラウザの View Transitions API）で、タブの切り替えはフェード（普通）
- 検索のカードから相手のプロフィールに移るときは、写真がそのまま大きくなってつながる（`view-transition-name` を写真に付ける）
- 使えないブラウザでは、動きなしで切り替わるだけ（そのままで困らない）
