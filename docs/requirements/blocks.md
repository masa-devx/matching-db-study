このファイルは、相手をブロックする・ブロックを解除する・ブロックした／された相手をどこにも出さない、を長く表す。レガシー版も改善版も、この要件を守る（レガシー版で守れていないものは、改善する段階のテストの対象になる）。要件 ID は `FR-BLOCK-` で始める。画面の要件は [screens.md](screens.md) に `FR-UI-` で書き足す。

## 目的と対象

会いたくない相手を、自分から見えなくし、相手からも自分が見えなくなるようにする。消さずに隠すので、解除すれば元に戻る。

## ユーザーストーリーと優先度

- 会員として、会いたくない相手をブロックし、検索・いいね・マッチ・メッセージのどこにも出ないようにしたい
- 会員として、ブロックした相手から、いいねもメッセージも届かないようにしたい
- 会員として、まちがえてブロックした相手を、あとで解除したい

優先度ごとの範囲：

- 必須（06）
  - ブロックする
  - ブロックした相手の一覧
  - 解除する
  - 検索／いいね／マッチ／トークの一覧／トーク／プロフィールから、ブロックした・された相手を除く
- 次の段階：通報（`reports`。管理画面 12 で見る）・管理者がブロックを見る（12）
- 対象外：ブロックしたことを相手に知らせる・ブロックの理由・期間を決めたブロック

## 機能要件と受け入れ条件

ブロックは、ブロックした人とされた人の組を1行で持つ（`blocks`）。マッチ・トークルーム・メッセージ・いいねは消さずに残し、読むときに除く。「ブロックした」と「された」のどちらでも、お互いに出ない（向きを問わない）。

| ID | 機能要件 |
| --- | --- |
| FR-BLOCK-001 | 相手をブロックできる |
| FR-BLOCK-002 | 同じ相手を2回ブロックしても1つ |
| FR-BLOCK-003 | 自分はブロックできない |
| FR-BLOCK-004 | いない会員はブロックできない |
| FR-BLOCK-005 | 検索に出ない |
| FR-BLOCK-006 | プロフィールが見えない |
| FR-BLOCK-007 | いいねを送れない・一覧に出ない |
| FR-BLOCK-008 | マッチの一覧に出ない |
| FR-BLOCK-009 | トークの一覧とトークに出ない・送れない |
| FR-BLOCK-010 | ブロックした相手の一覧を見られる |
| FR-BLOCK-011 | 解除すると元に戻る |
| FR-BLOCK-012 | 解除できるのは、ブロックした人だけ |

| FR-BLOCK-014 | ログインしていないと使えない |
| FR-BLOCK-015 | メールアドレスを確認していないと使えない（不変条件 2） |

### FR-BLOCK-001 相手をブロックできる

- 前提：A と B はどんな関係でもよい（マッチしていなくてもよい）
- 操作：A が B をブロックする
- 期待結果：`201`。A のブロックの一覧に B が出る

### FR-BLOCK-002 同じ相手を2回ブロックしても1つ

- 前提：A は B をブロックした
- 操作：A がもう一度 B をブロックする
- 期待結果：`200`（または `201`）。ブロックの行は1つのまま

### FR-BLOCK-003 自分はブロックできない

- 前提：なし
- 操作：A が A をブロックする
- 期待結果：`422`

### FR-BLOCK-004 いない会員はブロックできない

- 前提：なし
- 操作：A が、ない ID・退会した会員をブロックする
- 期待結果：`404`

### FR-BLOCK-005 検索に出ない

- 前提：A が B をブロックした
- 操作：A が検索する・B が検索する
- 期待結果：A の結果に B は出ない。B の結果に A は出ない。件数にも入らない

### FR-BLOCK-006 プロフィールが見えない

- 前提：A が B をブロックした
- 操作：A が B の、B が A のプロフィールを開く
- 期待結果：どちらも `404`（いることも分からない）

### FR-BLOCK-007 いいねを送れない・一覧に出ない

- 前提：A が B をブロックした。前に B から A へのいいねがある
- 操作：B が A にいいねする。A がもらったいいねの一覧を見る
- 期待結果：いいねは `404` で増えない。A の一覧に B は出ない（行は残る）

### FR-BLOCK-008 マッチの一覧に出ない

- 前提：A と B はマッチしていた
- 操作：A が B をブロックし、A と B がマッチの一覧を見る
- 期待結果：どちらの一覧にも出ない。マッチの行は残る

### FR-BLOCK-009 トークの一覧とトークに出ない・送れない

- 前提：A と B のルームにメッセージがある
- 操作：A が B をブロックする
- 期待結果：どちらのトークの一覧にも出ない。履歴を読む・送るは `404`。ルームとメッセージは残る

### FR-BLOCK-010 ブロックした相手の一覧を見られる

- 前提：A は B・C をブロックした
- 操作：A がブロックの一覧を開く
- 期待結果：新しくブロックした順に、相手の会員の ID（`public_id`）・ニックネーム・画像・ブロックした日時

### FR-BLOCK-011 解除すると元に戻る

- 前提：A が B をブロックしていた。A と B はマッチしていて、メッセージがある
- 操作：A が B のブロックを解除する
- 期待結果：`204`。検索・いいね・マッチ・トークの一覧とトークに、また出る。メッセージも元のまま

### FR-BLOCK-012 解除できるのは、ブロックした人だけ

- 前提：A が B をブロックした
- 操作：B が「A のブロック」を解除する
- 期待結果：`404`。ブロックは残る

### FR-BLOCK-013 お互いにブロックしたら、片方を解除しても出ない

- 前提：A が B を、B が A をブロックした
- 操作：A が解除する
- 期待結果：まだお互いに出ない（B のブロックが残る）

### FR-BLOCK-014 ログインしていないと使えない

- 前提：なし
- 操作：トークンなしでブロック・一覧・解除
- 期待結果：`401`

### FR-BLOCK-015 メールアドレスを確認していないと使えない（不変条件 2）

- 前提：A は確認していない
- 操作：ブロック・一覧・解除
- 期待結果：`403`（FR-AUTH-021）

## 成功基準・非機能要件・制約

- NFR-BLOCK-001：ブロックした・された相手を除いても、検索・いいね・マッチ・トークの一覧の SQL の本数が増えない（相手ごとに確かめない）
- NFR-BLOCK-002：ブロックの数が増えても、除く条件のために `blocks` を全部読まない
- 測るときの試しのデータ
  - 04 の会員 2万人・05 のメッセージに、ブロックを足す（`search00001` がブロックした相手・`search00001` をブロックした相手を混ぜる）
  - 速さの目標は決めず、記録する

## 前提と要確認事項

- 前提：ブロックは消さずに隠す。マッチ・トークルーム・メッセージ・いいねは残す（解除で戻すため。通報や管理画面 12 で中身を見られるようにするため）
- 前提：ブロックした・された相手を除く条件は、検索（04）・いいね（02）・マッチ（03）・トーク（05）のすべての読み取りに要る。レガシー版は、コントローラごとに条件をコピーする（コピーし忘れを測る）
- 前提：Firestore 版（05c）には足さない（改善版のときに決める）
- 要確認：なし
