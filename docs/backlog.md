# バックログ（足りない機能と、直したほうがよい所）

2026-11-17 に、会員の側と管理画面を1ページずつ読んで洗い出したもの。実務のバックログと同じく、まとまり（エピック）に束ね、大事さと大きさを付けて、上から順に取り組む。

- 洗い出したのは、使う人（会員・運営）から見て「この機能がない」「この動きは分かりにくい・不便」というもの。コードの作りと、`docs/api/` の「レガシー版で起きること」に書いてある不具合は、ここには入れない（改善版で直す）
- 調べたのはコードと文書で、画面は動かしていない。取り組むときに、画面で確かめてから直す
- 進める順：設定画面（M1）→ 会員の側の残り → 管理画面（2026-11-17 に人が決めた）

## 見方

| 列 | 中身 |
| --- | --- |
| 大事さ | 高：ないと、アプリの中心の流れ（登録 → 探す → いいね → マッチ → メッセージ）が止まる・安全に関わる・お金の案内が違う／中：あると、続けて使ってもらいやすい／低：あると便利 |
| 大きさ | 画面：画面だけで直せる／API：API も要る／表：DB の表や列も要る |
| 要件 | ある：要件 ID／次：要件の「次の段階」にある／対象外：やらないと決めてある（やるなら、先に要件を決め直す）／ない：要件にまだない |
| 状態 | 済み：直した（Issue の番号）／空欄：まだ |
