DB 設計の学習ノート（マッチングアプリ）

マッチングアプリ（会員・いいね・マッチ・メッセージ・有料プラン）を題材に、テーブル設計・JOIN・中間テーブル・インデックス・同時更新を、作って確かめる。実在のサービスのコード・名前・データは使わない。

技術: Laravel（API）＋ PostgreSQL、画面は React（03b から）。

2つの版がある
版ブランチ何をするか目次
レガシー版legacy-repo一歩（機能）ごとに解説を作り、わざとレガシーコード（Fat Controller・テストなし）で作り切る。そこで起きる問題を測って記録する1. レガシー版の目次
改善版refactored-repoレガシー版で測った問題を、現場と同じ開発サイクル（なぜ → 何を → どう → チケット → 実装 → レビュー）で直す。テストを先に足し、前と後を比べる2. 改善版の目次
